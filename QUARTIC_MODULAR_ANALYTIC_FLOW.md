# One quartic analytic flow: real time and imaginary screening

## The result

The primitive quartic graph fixes its critical modular scale at

```text
beta_Q = log Q.
```

On a degree-one graph mode, define the entire analytic multiplier

```text
F_Q(z) = exp(-i beta_Q z).
```

Lean proves the following exact identities for every positive `Q`:

```text
F_Q(z+w) = F_Q(z) F_Q(w),
|F_Q(t)| = 1                    for real t,
F_Q(-i) = exp(-beta_Q) = 1/Q,
1 - F_Q(-i) = 1 - 1/Q = lambda4.
```

This is an analytic relation, not a numerical fit.  The quartic Perron value
fixes `beta_Q`; no extra scale is inserted between the graph and these four
identities.

## What it says in physical language

On the real axis, the graph mode only changes phase.  It rotates without
losing norm, which is the mathematical form expected for reversible modular
time evolution.  Moving the same analytic flow by one unit in the
negative-imaginary direction turns that phase into the positive contraction
`1/Q`.  The fraction absent from the surviving channel is therefore exactly

```text
lambda4 = 1 - 1/Q.
```

The repository had already proved that `lambda4` has a unique
norm-preserving two-channel completion, whose complementary squared weight is

```text
S_Q = 1 - lambda4^2.
```

It had also carried that completion through the reduced spin-two null
boundary dynamics.  The new theorem supplies the missing analytic relation:
the reversible time phase and the contraction that seeds the gravity
screening map come from the same graph-selected modular frequency.

This does **not** say that the splitter angle is `log Q`.  The two quantities
are different:

```text
real modular phase per unit:       log Q,
two-channel completion angle:      arcsin(lambda4).
```

The first belongs to the analytic modular flow.  The second is fixed later by
the unique real norm-preserving completion of its imaginary-step defect.
Keeping those stages separate prevents a false phase identification.

## Why the operator-algebra placement matters

The quartic graph has coprime return loops of lengths four and seven.  Together
with the graph KMS and factor-classification theorems cited in
`QUARTIC_GRAPH_KMS_SCALE.md`, the corresponding equilibrium representation is
a hyperfinite type `III_(1/Q)` factor.  Its discrete modular ratio group is
generated by `1/Q`.

Local relativistic quantum-field algebras, including the setting used for
null modular dynamics, are generally type `III_1`.  The quartic graph factor
therefore has a precise candidate role: a discrete modular sector or
subalgebra carried covariantly inside the continuous horizon algebra.  It
cannot be the whole local horizon algebra.

The relevant physics literature gives the other half of this proposed
placement.  Null-plane vacuum modular Hamiltonians generate local flow along
each null generator, and null gravitational initial data admit an intrinsic
canonical potential and flux.  These facts make a modularly covariant graph
sector on a null boundary a concrete construction problem rather than a
verbal analogy.

## The exact bridge still to construct

The remaining physical statement is an intertwining theorem.  One must
construct a representation `pi` of the quartic graph sector in a null-horizon
observable algebra such that

```text
pi(sigma_t^Q(a)) = Delta_H^(it) pi(a) Delta_H^(-it)
```

for the graph modular flow `sigma_t^Q` and the horizon modular operator
`Delta_H`, while preserving the reduced spin-two canonical pairing already
formalized in this repository.

The companion construction in `RHO_Q_MODULAR_COMPLETION.md` now removes the
abstract factor-type part of this problem.  Tensoring the cubic and quartic
graph-KMS sectors gives two discrete modular ratios with irrational log ratio;
the published Araki--Woods classification therefore makes the product
hyperfinite type `III_1`.  What remains here is the **physical** placement of
that concrete product representation in the null-horizon algebra, with its
modular parameter and spin-two canonical data preserved.

Exact covariance matters.  If the equation holds with the physical modular
parameter `t`, an arbitrary rescaling of `log Q` is unavailable: the graph
KMS state has already fixed that scale.  The construction would then carry
the sequence

```text
quartic graph
  -> beta_Q = log Q
  -> imaginary modular ratio 1/Q
  -> defect lambda4
  -> complementary weight sqrt(S_Q)
  -> null spin-two response
```

into a recognized quantum-field-theoretic setting.

This proposal is falsifiable at the structural level.  It fails if no
parameter-preserving modularly covariant representation can preserve the null
canonical data, or if the candidate horizon sector has a modular spectrum
incompatible with the discrete group generated by `1/Q`.

The finite erasure map should not be declared a conditional expectation onto
a nontrivial half-sided modular subalgebra.  Published results rule out such a
conditional expectation in the relevant standard setting.  The visible and
hidden channels must instead arise after restricting the state or
representation of the covariantly embedded graph sector.

This restriction is specific to a nontrivial half-sided modular inclusion.
The cubic--quartic construction uses an ordinary tensor-factor inclusion,
which does have the canonical product-state slice map.  Whether that slice map
is the physical gravitational channel is a separate proposed identification.
