# From the bulk quartic Hamiltonian to the horizon splitter

## The new result

The doubled first-order action and the horizon interface are now connected by
one canonical Hamiltonian calculation.

For a single mode, write the normalized bulk Hamiltonian as

```text
             q^2 - 2 lambda q p + p^2
H(q,p) =     ------------------------- ,
                         2 d

d^2 = 1-lambda^2.
```

Lean differentiates this function and proves Hamilton's equations exactly:

```text
qdot =  (p-lambda q)/d,
pdot = -(q-lambda p)/d.
```

Equivalently, for `z=(q,p)`,

```text
zdot = G z,

      1  [[-lambda,  1],
G =  -  [             ]].
      d  [[      -1, lambda]]
```

The determinant identity `d^2+lambda^2=1` then gives

```text
G^2 = -I.
```

This is stronger than saying that the two-channel response resembles an
oscillator.  It proves that the bulk Hamiltonian vector field is a genuine
complex structure: every mode carries a unit-frequency rotation after the
canonical source normalization.

## Why the apparently squeezed dynamics is an ordinary rotation

Let `T_e` be the positive determinant-one electric source frame already fixed
by the sourced constraint analysis.  Its Gram matrix is the normalized
constitutive block, and its inverse preserves a purely ordinary source.  Lean
now proves the exact conjugacy

```text
T_e G T_e^(-1) = -J,

J = [[0,-1],
     [1, 0]].
```

Thus the off-diagonal quartic coupling is a squeeze in the original canonical
coordinates and a plain rotation in the source-adapted coordinates.  The same
frame that resolved source mixing also removes the apparent anisotropy of the
bulk Hamiltonian flow.

The proof includes the general covariance statement: every implicit-midpoint
trajectory of `G` maps under `T_e` to an implicit-midpoint trajectory of
`-J`.  This change of variables is proved inside Lean rather than assumed in
the narrative.

## The boundary map has an algebraic Cayley coordinate

For the normalized rotation generator, the centered Cayley equation with
coordinate `h` is

```text
z_after-z_before = (h/2)(-J)(z_before+z_after).
```

Set

```text
t = lambda/(1+d),
h = 2t.
```

Lean proves that the midpoint equation is exactly

```text
(I+tJ) z_after = (I-tJ) z_before,
```

and hence has the unique transfer matrix

```text
z_after = [[d,       lambda],
           [-lambda,      d]] z_before.
```

This is precisely the passive source splitter previously obtained by
Gram--Schmidt completion of the action-selected source column.  The proof now
reaches the same matrix by three independent descriptions:

1. the unique orientation-preserving completion of the sourced Gram factor;
2. the canonical transformation generated by the quadratic boundary action;
3. the centered Cayley form of the normalized bulk Hamiltonian flow.

Lean proves these are equal maps, not merely matrices with the same numerical
entries.

## It is also the exact continuous flow

The Cayley equation does not need to be interpreted as a numerical
approximation.  Define the positive phase

```text
theta_Q = arcsin(lambda_Q).
```

Lean proves

```text
sin(theta_Q) = lambda_Q,
cos(theta_Q) = d_Q,
0 < theta_Q < pi/2.
```

It then proves directly that

```text
R(theta) = [[ cos(theta), sin(theta)],
            [-sin(theta), cos(theta)]]
```

is a one-parameter group whose trajectories satisfy `qdot=p` and `pdot=-q`.
At `theta_Q`, this exact continuous Hamiltonian flow is the passive splitter:

```text

              [-lambda_Q,      d_Q]].
```

Lean also proves uniqueness: on the principal phase interval
`[-pi/2,pi/2]`, equality with the splitter forces `theta=theta_Q`.  It proves
in a separate theorem that the earlier algebraic Cayley transfer and this
exact continuous flow are literally the same matrix.

Conjugating this flow back through the electric source frame gives the exact
flow in the original bulk coordinates.  Lean proves its identity and
composition laws and proves that transforming its quartic endpoint to the
source frame gives the passive horizon splitter.

Thus `2t_Q=2lambda_Q/(1+d_Q)` is the rational Cayley or half-angle coordinate
of the exact phase `theta_Q`.  It is not itself a numerical approximation and
should not be identified with a physical duration without a dimensionful

## The explicit boundary action

The matching map has the type-one generating function

```text
                         d

                        2 lambda
                      + q_before q_after/lambda.
```

Lean computes both partial derivatives and proves that the canonical boundary
conditions

```text
p_before =  partial_before F,
p_after  = -partial_after F
```

are equivalent both to the passive splitter and to the midpoint equation.
The interface law is therefore variational: it comes from an explicit
quadratic boundary generator and acts on the same canonical pair as the bulk
first-order action.

The relation is stronger than agreement of the endpoint equations.  In the
electric source frame, Lean proves that the squeezed bulk Hamiltonian becomes
the unit oscillator Hamiltonian

```text
H_osc(q,p) = (q^2+p^2)/2.
```

For a phase `theta`, define

```text
S_theta(q_before,q_after)
  = [cos(theta)(q_before^2+q_after^2)/2
     - q_before q_after] / sin(theta).
```

With the sign convention used above, `F_theta=-S_theta`.  Lean proves the
Hamilton--Jacobi identity

```text
partial_theta F_theta
  = H_osc(q_after,p_after),

p_after = [cos(theta) q_after-q_before]/sin(theta).
```

It also proves that at `theta=theta_Q`, `F_theta` is exactly the quartic
horizon generating function.  Thus the boundary functional is the Hamilton
principal function, up to the stated sign convention, of the same normalized
bulk flow whose endpoint is the splitter.  At the fixed-mode level it is
derived from the on-shell bulk dynamics rather than supplied as an independent
quadratic ansatz.

The normalized oscillator is itself derived from the spin-two theory.  On

where the phase variable is `tau=k t`.  The negative-helicity mode requires

## Fully specialized quartic chain

For the positive quartic root `Q`, every continuous quantity in the theorem is
a fixed function of `Q`:

```text

r_Q      = sqrt(d_Q),
T_Q      = electric source frame(lambda_Q,r_Q),
```

One capstone theorem states that if the original bulk canonical data obey the
centered Cayley form with parameter `2t_Q`, then the data in the canonical
electric source frame obey exactly the passive quartic splitter.  A stronger

coefficient, or output normalization in either statement.

The dimensionless Cayley coordinate is

```text

```

It should not be called a measured duration.  Relating the exact phase to a
physical time interval requires a dimensionful scale and a physical rule
identifying one horizon crossing with that amount of Hamiltonian phase.

## What remains physical

The old algebraic seam has closed: the bulk action, source frame, exact flow,
Hamilton principal boundary function, Cayley equation, and passive splitter
now form one exact chain.  The remaining premise is narrower:

> A physical horizon crossing advances the source-normalized first-order
> spin-two mode through the fixed phase `theta_Q`.

This premise can be attacked directly.  The next step is to reduce a covariant
spin-two action and its null-horizon symplectic potential to one transverse
traceless mode, then compare its on-shell endpoint action with the principal
function above.  A different boundary polarization, phase relation, or
additional allowed boundary quadratic would show where the proposed mechanism
fails.

The existing canon result concerning a time tick as a commitment event does
not by itself establish this horizon phase.  Any identification of
`theta_Q` or its Cayley coordinate with that physical tick remains
conditional.
